# Simple software identity concepts

User feedback: the simpler software appearance is liked, but Lessonrail and Inlesson are rejected names and the pair still feels too visually similar. [Round 7](../round-7/README.md) explores multiple design methods across two UI treatments. Preserve this round as the accepted stylistic starting point, not an accepted final brand.

2026-10-19. Replaces the engraved-animal direction rejected as whiskey/hardware branding. The revised brief is a dark contemporary software identity appropriate to tutoring-center coordination, with an understandable name, restrained typography and a compact flat symbol.

## Research applied

- [Linear's official guidelines](https://linear.app/brand) prefer monochrome usage and favor the wordmark when space permits. This supports showing a name alongside a new symbol rather than expecting immediate recognition.
- [Cursor's official brand resources](https://cursor.com/brand) distinguish logos, app icons and avatars. Their assets are reference material, not source art for these concepts.
- [NN/g's icon usability guidance](https://www.nngroup.com/articles/icon-usability/) recommends reducing graphic detail to the characteristics that aid recognition. This is useful for the header symbol; it does not prove that every simple logo is distinctive or suitable.
- [Slack's official brand guidelines](https://a.slack-edge.com/0f43e/marketing/img/media-kit/Slack-Brand-Guidelines.pdf) provide a small-use logo variant. Actual production assets should likewise be checked at intended sizes instead of judging only a large presentation.

The resulting design criteria are flat one-color recognition, a clear silhouette, readable name, consistent proportions across uses, dark-background contrast, and a relationship to the application. Visual resemblance to familiar startups is not itself a success criterion.

## Name and mark premises

**Lessonrail**: a continuous supporting structure between learning sessions. The proposed connected-rail symbol expresses staff and student context remaining linked across visits. The product also works without homework, so the concept is not tied to sheets or packets. This name is more explicit about education, though it is longer and can suggest a lesson-delivery platform without explanatory copy.

**Inlesson**: a direct phrase about the active learning day. A compact i/l-derived sign connects the word to a student within a shared workspace. This is warmer and shorter, but may sound like a student-facing tutoring service or omit the between-visit history aspect. Staff-facing product copy must make the scope clear.

These are naming proposals, not cleared trademarks. Preliminary searches found no obvious exact-name software result for Lessonrail; Inlesson appears as the name of an education project. Neither name is claimed to be globally unique or domain-available. Other candidates were excluded after finding software products, including Daystep, Dayrelay, Stepframe, Keepline, Along and Classkeep.

## Visual assessment

1. [Inlesson](02-inlesson.png): stronger overall fit for the tutoring category and the revised warm, restrained software direction. The compact i/l interpretation is visually simpler than the animal round. It still needs a flat vector reconstruction, spacing refinement and recognition/similarity checks. Its name is clear but less broad than the product's complete scope.
2. [Lessonrail](01-lessonrail.png): more direct continuity metaphor, cooler and more structured. The generated mark reads as a step and its typography is less distinctive. The long name also takes more header space. It is a useful contrasting direction, not a finished identity.

Both generated boards retain subtle raster texture and show colored rather than pure monochrome primaries. They do not establish exact 24px legibility, and the bottom website crops are illustrative. These limitations should be addressed before production, not concealed by presentation size.
