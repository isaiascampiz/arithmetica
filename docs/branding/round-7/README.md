# Four identity approaches across two dark UI directions

2026-10-19. The user liked round 6's simpler software style but rejected both names and requested greater variation between identities. The application UI is being explored separately in a warm Claude-inspired direction and a cool, precise Linear-inspired direction. This work does not modify that experiment.

## Brief

Keep the identity compact, professional and legible in an adult staff workspace. It should suit attendance, observations, handoffs, activities and progress history, including configurations without homework. Avoid making the product look like a chatbot or implying it replaces tutors. The logo should remain recognizable when its surrounding interface changes.

Each board requests a large identity plus two small context studies: warm charcoal/chalk/clay and cool near-black/silver/indigo. These are approximate styling comparisons, not copies or screenshots of Claude, Linear or this application's actual interface. The local [Claude theme experiment](../../../src/app/claude-theme.css) was read for context; it currently uses warm near-black, chalk text and a clay accent. No theme file was edited.

## Research and naming status

[Linear's brand guidance](https://linear.app/brand) favors monochrome usage and a wordmark where space permits. [Cursor's official brand resources](https://cursor.com/brand) were also reviewed. Their actual logos are not source artwork. The aim is comparable discipline and usability with original forms, rather than borrowing recognizable marks.

Preliminary searches found Cadrin in surnames and construction businesses, Cohren in personal names/usernames, Tandren as a retail name and game-creator handle, and only an incidental historical result for Rungwell. These results do not establish exclusivity, trademark clearance, domain availability or absence of software conflicts. Cohren may also be misheard or misspelled as other names; pronunciation should be checked with people before choosing it.

Excluded names included Pace, Stride, Tandem, Aven, Cadren, Ordin, Tervi, Forthen and Sideby after finding existing software or education uses. [PACE](https://paceattend.com/) is especially close to this product's category: check-in software for Kumon and tutoring centers.

## Assessment after viewing the boards

1. [Cadrin](01-cadrin.png): strongest match for a precise engineering-oriented application. The wordmark-first treatment avoids another generic symbol-plus-sans pairing. The C still needs comparison with other C marks and optical refinement; the standalone sample should not be used alongside the full wordmark as a second logo in production.
2. [Cohren](02-cohren.png): the most fluid contrasting direction, with a broad curve and lighter type. It spans both palettes visually, but the curve is still generic enough to need further distinctiveness work, and the spelling/pronunciation is less obvious.
3. [Tandren](03-tandren.png): warmer, more editorial and most comfortable in the Claude-inspired context. Its serif and geometric symbol contrast clearly with the other two. It risks returning toward institutional branding if the serif or presentation becomes more ornate. The generated symbol is more angular than requested.
4. [Rungwell](04-rungwell.png): weakest result. The condensed wordmark suggests hardware, the glyph reads as an E, and the name feels less natural for software. Retain as an explored alternative; do not advance this version.

The large monochrome marks help expose structural differences, but the warm/cool UI panels mostly vary palette and density rather than demonstrating complete interface systems. Some fine raster texture remains despite the flat-art brief. These panels are useful compatibility studies, not proof of UI fidelity, production contrast, exact icon sizes or logo consistency at every scale. Ranking is a design judgment, not a user acceptance result.

Four original AI-assisted raster boards were requested through the built-in image-generation tool. No existing logo assets were supplied or traced. [Complete prompts](prompts.json) are retained. These are exploration images, not accepted names, finished vector masters, actual app screenshots, tested icon-size assets or independently verified unique marks. The same identity is requested in both UI contexts so color alone does not stand in for design variation.
