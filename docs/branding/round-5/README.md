# Dark emblem identity studies

Status: rejected by the user as whiskey/hardware branding. See [round 6](../round-6/README.md) for the revised simple software direction. The ranking below records the earlier assessment and is not a recommendation to continue this style.

2026-10-19. Original name-and-emblem concepts responding to the preference for dark, sophisticated, figurative identities with controlled detail. The Lucid bear, Merrill Lynch bull, Makita lettering and Hermès craftsmanship are references for qualities, not assets to reproduce. The exact TikTok advertisement was not available.

## Product basis

The application coordinates student presence, subject activities, physical work, instructor handoffs and observations, retaining context across visits. It also supports activity-only configurations. The identity therefore needs to cover staff awareness and student continuity, rather than only homework or paper preparation. See [the previous product review](../round-4/README.md#product-premise).

## Concepts

Visual ranking after inspecting the generated studies:

1. **Vespern** — the strongest combination of dark palette, emblem and quiet typography. Its fine feather cuts still need reduction; the owl can drift toward fantasy branding if exaggerated. [View study](03-vespern.png).
2. **Rookward** — substantial and institutional, with the most direct name metaphor. The bird drawing has some sports-mascot tension, the under-wordmark ornament is unnecessary, and the generated header uses a light surface despite the dark-theme brief. [View study](01-rookward.png).
3. **Sablis** — shortest name and a clear silhouette, but the illustration reads more like a fox than a sable, while the slanted lettering still suggests automotive branding. This needs a larger revision than the other two. [View study](02-sablis.png).

The generation did not fully achieve the requested flat one-color and simplified-header masters. Texture, shading and inconsistent fine details remain. The boards communicate directions; none should be installed as a finished production identity.

- **Rookward** — ROOK-ward. Rook plus ward: an alert bird and a name suggesting attentive stewardship. The engraved rook and substantial lettering are conceived together.
- **Sablis** — SAB-liss. A proposed coinage inspired by sable. A poised sable/marten, expressive tail and assertive lettering form a less literal identity.
- **Vespern** — VES-pern. A proposed name inspired by vesper/evening. A watchful owl and sturdy lowercase lettering explore a quieter nocturnal identity. The spelling is a creative proposal, not a claim about Latin etymology.

Each study requests a large flat emblem, a compact header interpretation and a restrained metallic finishing example. These are AI-assisted raster concepts generated with the built-in image-generation tool, not vector masters, verified small-size proofs or actual application screenshots. Simplified variants need manual reconciliation before production. Full prompts are retained in `prompts.json`.

Preliminary exact-name searches did not surface an obvious same-name software product for these three candidates. Rookward also appears in fiction, Sablis as a surname, and vespern in German. This is not trademark clearance or a claim of domain availability or worldwide uniqueness. Candidates with obvious software uses, including Rooken, Corvane, Vulpin and Arcten, were excluded.
