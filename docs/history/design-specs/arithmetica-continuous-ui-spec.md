# Arithmetica: refined operational workspace

Latest follow-up: [appearance, shared headers and immersive reception](arithmetica-appearance-header-spec.md). The new brief supersedes the fixed accent, inner Traffic rail and earlier reception artwork below.

Current implementation brief, 28 October 2026. The latest user direction supersedes earlier isolated punch-history screens and packet-count fields.

## Visual direction

Preserve the established navigation and operational structure. Use the existing local Figtree interface font, neutral dark default, EB Garamond editorial reception headline, 44px controls, 6-8px radii, and one outline icon family. A flat dissected-square mark replaces the isometric mark. Reception uses local lilac, sage and peach accents; student chart palettes stay unchanged. Public [Wispr Flow](https://wisprflow.ai/) and the previously inspected Windows screens inform the hierarchy and native overlays. No third-party logo, source code or new dependency is used.

## Layout and interaction

- **Subject overview/editor:** keep Details/Enrollment beside Math/Reading. Always retain both subject tabs and four readout categories. Hide values and medals when unenrolled; restore saved configuration on reenrollment. A compact dialog uses Enrolled, Learning mode + Current level, then Current/Starting worksheet + Worksheets per day. Remove the redundant next-planned and packet-count fields. Explicitly edited daily allocations follow ten-sheet standard packet boundaries, preserving smaller portions and prior issued/prepared material.
- **Directory filters:** Early learner first, Subject/Format together, visit weekdays last; one shared left-aligned dialog and toolbar for roster/preparation. Refresh sits at the right of preparation's status rail. Preparation identity uses Home's avatar/name/subject/readiness hierarchy, with Expected and return date at right. In-center and homework ranges share 96 x 48px tiles. Quick View keeps its compact 104 x 60px tiles, including crossed-out work.
- **Traffic:** put student search and date navigation outside one continuous card. Full-width underlined Daily/Weekly/Monthly/Yearly rail. Daily shows a seven-hour viewport with all hours accessible by scrolling; weekly includes every weekday, monthly every day, yearly twelve calendar months. Group day actual/expected and selected-hour actual/expected in two readable panels. Weekly shows period totals; monthly/yearly show recorded arrivals. Gray comparison and teal actual share the same bar width. Five integer Y ticks and a legend containing only Recorded/Typical. Hover, tap or keyboard inspection reveals exact values. The optional Punches disclosure follows the same selection/search. Expected arrivals are historical matching-weekday estimates, never occupancy or completion evidence.
- **Reception:** pouch reader and inline name completion share the page; no camera block until requested. Three normalized characters initiate a name-only server lookup. Ambiguity waits for more letters; no dropdown. Tab/Right Arrow accepts the completion; Continue resolves the unique name. A named, durable confirmation receipt prevents retries toggling attendance. A scan signal replaces the logo illustration. Check drawing/core entrance lasts 260/280ms; an outward receipt ring lasts 480ms to echo a successful scan, with no continuous motion. Reduced motion uses a 150ms opacity fade. Editing controls elsewhere retain the settings-dialog pattern.
- **Reports and progress:** preserve the continuous counted report sections, monthly Excel export, frozen evidence and the four existing student progress graphs. No new accent-color preference or active legacy workflows.
